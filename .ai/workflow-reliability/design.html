4. Data & contracts

SourceSnapshot needs no workflow. Later ContractBinding explicitly adds current component/check hashes. workflow.json owns forward edges/commands; current-design.json points to history; the ledger owns runtime facts. Replay/status are derived. Own generated outputs do not invalidate source proof.

Metric v2 separates measured regression from completeness. Unknown baseline is not greenfield; stale reports cannot become new measurements. Missing proof fails without imports, exemptions or adoption. Mutation stays 60%; eval stays 0.9. Known-greenfield cycles fail under the existing no-new-cycle rule.

5. Decisions & failure behavior

  • Explicit argv, not shell text: preserve spaces and package cwd independently of Git root. Node events must identify relevant assertions; syntax, setup, empty suites and timeouts never kill mutants. Unsupported runners remain unavailable.
  • Observed ownership, not a supervisor: persist launch intent and actual child events. The spawn-to-record crash gap remains unknown; dead guard/PID age cannot unlock it. Recovery needs supported termination evidence, otherwise stays blocked.
  • Observed scope, not sandbox: hashes detect only scoped input changes. Review owns scope completeness. Identity is self-declared; outside-scope writes remain unobserved. Keep owned scratch cleanup, without a product-wide OS-temp ban.
  • Scoped reopening, not full reset: changed prerequisites invalidate dependent proof only. Old red/compatibility proof remains historical; retirement requires its admission before deletion, never a later backfill.
  • Fail closed: blocked gate exits 1, malformed input 2, lock/recovery conflict 3. Executed children preserve exit/timeout codes and carry a separate structured outcome. Approval is not inferred from silence.
