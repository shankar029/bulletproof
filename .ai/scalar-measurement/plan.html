Implementation constraints

Reuse graph path/JSON/artifact primitives and run.run_capture. External tools remain read-only, qualified and pinned. Missing packages or integration contracts are concrete stops, never auto-install or success-shaped fallback. Failed evidence stays visible. Tool output is decoded, not trusted as a metric; validation must replay/rederive source-bound results. Dynamic sites and finite lexical models stay explicit.

Regression and delivery boundary

Use managed Python -B, UTF-8 and bounded run.py commands. Native parser retains idle 30/max 90. Targeted scalar tests first; full combined scope only after parent releases frozen controllers. No PR/push (existing 403/EMU restriction). Publication, coverage/mutation and whole-Q acceptance are not claimed by this slice.
