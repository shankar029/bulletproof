3. Key interaction

4. Data and HTTP contracts

GET /api/projects?archived=false|true defaults false; unknown/duplicate/invalid queries fail. New GET/PATCH /api/projects/:id uses {project, revision}; PATCH accepts exactly {archived:boolean}. New GET /api/projects/:id/tasks.csv returns UTF-8 CSV, no-store, revision ETag and attachment project-p-N-tasks.csv. Detail/export take no queries. Global tasks/dashboard remain inclusive.

CSV: ascending createdOrder, every task regardless of filters/page. Headers: projectId,projectName,id,title,description,status,priority,dependencyIds,blocked,createdOrder. Dependencies are JSON array text. No BOM; CRLF records including final record; quote every cell, double quotes, preserve embedded newlines/Unicode. Prefix text with apostrophe if first non-whitespace/control character is = + - @, or it starts with tab/CR/LF. Stored data stays unchanged; empty projects export headers.
